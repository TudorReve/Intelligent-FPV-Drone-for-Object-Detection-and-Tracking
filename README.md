# Intelligent-FPV-Drone-for-Object-Detection-and-Tracking
I built a 5-inch FPV drone from individual components, performing all soldering and Betaflight configuration. I integrated a Raspberry Pi 5 with an Oak-D Lite camera and trained a YOLO model to detect cars and people, estimating their positions using GPS, IMU, and flight data, with future plans for autonomous tracking.
